# 教材與模型審查

Issue → 重現／來源核對 → 小範圍修正 → 驗證 → 維護者審查 → 發布紀錄。

每個學科 PR 說明：學習目標、已知假設與適用範圍、符號／單位、可手算的正常案例、極端／邊界案例、參考來源；模擬或假設數據需標示。變更數值模型時，優先以獨立解析解或外部可驗算結果檢查，避免用同一套實作自我比對。

檢查狀態分開記錄：「待重現」、「來源待查」、「程式檢查通過」、「待學科審校」、「已審查」。程式測試通過不自動等於學科審校完成。若還沒有教師參與，直接標示待審校，不自行掛教師背書。

初期可認領的小任務：回報一個手機操作問題；補一個模型適用範圍；驗算一個題目並記錄步驟；補足一個來源連結。進度用公開 Issue／PR 與發布紀錄呈現，不先承諾外部參與人數。
